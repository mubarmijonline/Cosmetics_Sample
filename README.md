# Cosmetics — Demo Store (AR)

Interactive RTL Arabic storefront sample for client approval. Static site: no build step and no backend.

**Pages:** home, shop (filters, sort, search), product, bundles, routine quiz, cart, checkout, order confirmation, orders, account and wishlist, membership and points, about / FAQ / contact, policies.

**How it works:** `data.js` holds the sample catalog, `app.js` renders every page and keeps cart, orders, wishlist, points and reviews in the visitor's browser (`localStorage`). Nothing is sent to a server and no real orders are placed.

**Samples to replace:** brand name, product names, prices, claims, illustrations, reviews (labelled as samples), policies and contact details.

Demo promo code: `WELCOME10`.

Live preview (after enabling GitHub Pages on `main` / root): https://mubarmijonline.github.io/Cosmetics_Sample/
